Patterns to catch automatically

Fixed replacements

Each value a pattern catches gets a numbered placeholder, and that pairing is remembered so the same address always becomes the same placeholder — across messages and sessions. De-anonymize reads the same table backwards, which is why it is saved, encrypted, with the password above. Delete the table and anonymized text you kept elsewhere can no longer be reversed, so export a backup.

Patterns are literal matchers, not judgement: a version number like 1.2.3.4 is caught as an IPv4, an invalid one like 10.4.2.300 is left alone, and a hostname, account name or ticket reference is not caught at all unless you list it below. Scan before you share, and read the result.
